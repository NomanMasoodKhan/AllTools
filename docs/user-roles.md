# User Roles

CyberMart has exactly four platform roles.

## 1. Visitor (Unauthenticated)
- Browse tools
- View categories
- Read reviews
- Cannot submit tools
- Cannot leave reviews

## 2. Buyer (Authenticated)
- Save tools
- Review tools
- Contact developers
- (Later) purchase tools

## 3. Developer / Vendor
- Create profile
- Submit tools
- Update listings
- View analytics

## 4. Admin
- Approve tools
- Verify developers
- Moderate reviews
- Feature listings
