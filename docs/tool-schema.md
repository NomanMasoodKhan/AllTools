# Tool Listing Schema

Every tool listing must include the following fields.

## Required
- Tool name
- Short description (1–2 lines)
- Long description
- Category (from `docs/categories.md`)
- Tool type (script / SaaS / rule pack / framework)
- Supported platforms (Linux, Windows, Cloud, etc.)
- Deployment type (agent, API, CLI, cloud)
- Pricing model (free / paid / freemium)
- Developer profile link

## Trust Fields
- MITRE ATT&CK techniques (optional)
- Use cases
- Known limitations
- Tested environments
- Screenshots / demo links
- Documentation link

## Meta
- Version
- Last updated
- Tags
